Metamorph is a file converter for Linux that lives under your cursor. Drag any file, hold Shift, and a wheel of formats opens right where you are. Nothing to open, nothing to upload.

        Install in a minute.

        No root needed. The installer sets up its own Python environment, brings ffmpeg and pandoc if you don't have them, and adds a menu entry and a Files shortcut on F4.

        • Linux with an X11 session
        • Python 3.12 or newer, GTK 3 bindings
        • Optional: LibreOffice for slides and legacy Office files
        Terminal 
        $ git clone https://github.com/karygauss03/metamorph.git
$ cd metamorph
$ ./install.sh
